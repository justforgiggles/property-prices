# Prop Radar naming and cloud identity

Use Prop Radar for display names, prop-radar for project identifiers, and
prop_radar for Python imports. Keep the existing GitHub repository address,
account identities, and live form filenames so their consumers remain valid.
Builds and deployments share the prop-radar service account for a simpler setup;
it therefore holds both build and deployment permissions. GitHub federation
remains restricted to this repository's release workflow on main.
